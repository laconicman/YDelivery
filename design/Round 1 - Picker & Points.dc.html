2b

Multi-point ladder — 2, 5, 10+

symbols for the ends, numbers for the middle (§2.2, revised)

Two points keep the A→B reading. From three, intermediates become numbered circles that survive reordering. Past eight the list scrolls inside the card, a summary row replaces per-point contact lines, and the map clusters — the degenerate case stays usable rather than pretty. Point type (забрать / доставить / вернуть) is a per-row control, since the API models return points as first-class.

2c

Pin & badge spec

shape and glyph carry the role; color only reinforces

Grayscale column is the test: every row must stay distinguishable with color removed. Because that holds, the palette can keep the market's green/red reading — moved to Okabe-Ito green and vermillion so the pair also survives protanopia. Map marker and list badge use the same glyph, which makes the route list the map's legend.

Ends are symbols, not letters. A and B were map-app shorthand borrowed without reason: they carry no meaning, they need localizing thought at accessibility sizes, and they collide with numbered intermediates. Start becomes a concentric ring (smallcircle.filled.circle), which is the origin mark every map already uses; end keeps the teardrop (mappin.circle.fill). Where a row must state the action rather than the position — the multi-point list, where every stop is somebody's doorstep — pair them with shippingbox.fill for «забрать» and house.fill for «доставить». Verify each in the SF Symbols app against the iOS 17 floor before it lands in the catalog.
