Отправьте посылку так же просто, как ставите точку на карте. YDelivery — приложение доставки для людей и малого бизнеса: закажите с карты, увидьте цену до подтверждения, узнайте о прибытии курьера, поделитесь отслеживанием, повторите прошлый рейс в один тап.

Службы доставки подключаются за одной границей. Первая интеграция — API Яндекс Доставки «Экспресс» (B2B Cargo) — неофициальная, на условиях вашего бизнес-кабинета.

• Заказ с карты, а не по координатам — точки на карте, сохранённые места, недавние адреса, вставка ссылки.
• Цена до подтверждения — все тарифы на листе проверки до тапа.
• Каждый отправленный заказ на всех ваших устройствах — синхронизация через личный iCloud, поиск по адресам и вашим полям.
• Страница, которую не нужно обновлять — уведомление о каждой смене статуса и Live Activity на экране блокировки.
• Поделитесь доставкой, не делясь аккаунтом — получатель или коллега следит за заказом, чат по заказу, подтверждение получения — без входа в Яндекс.
• Планы меняются — отмена с показанной стоимостью до тапа.
• Библиотека отправителя — шаблоны посылок, закреплённые места и поля для ваших накладных.

Требуется бизнес-аккаунт Яндекс Доставки и его API-токен — ваш кабинет, на бизнес-условиях. Доставка оплачивается Яндексу по бизнес-аккаунту.
