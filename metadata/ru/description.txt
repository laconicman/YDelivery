YDelivery — неофициальный клиент для бизнес-аккаунтов Яндекс Доставки: Express API в кармане, без бэкенда и без интегратора.

Оформляйте заказы с карты, а не по координатам: точки выбираются визуально, есть избранные места и недавние адреса, можно вставить ссылку. Цена видна до подтверждения — все тарифы заранее, — а прошлую поездку можно повторить одним нажатием.

Все отправленные заказы остаются на каждом вашем устройстве: синхронизация через личный iCloud, поиск по адресам и вашим полям. Приложение обновляется само: уведомление о каждой смене статуса и Live Activity на экране блокировки — страницу не нужно обновлять вручную.

Делитесь доставкой, не делясь аккаунтом: получатель или коллега следит за заказом, общается в чате заказа, подтверждает получение — без логина Яндекса. А если планы изменились, отмена показывает стоимость до нажатия.

Требуется бизнес-аккаунт Яндекс Доставки и его API-токен — ваш кабинет, на бизнес-условиях. Доставка оплачивается Яндексу с вашего бизнес-счёта. Приложение не связано с Яндексом и не одобрено им.
